# 3D Endless Runner website

Static site (HTML + CSS, no build step) for GitHub Pages.

## Images (optional)
Drop these files in `images/` (the site looks fine with gradients if they're missing):
hero.jpg, about.jpg, about-controller.jpg, service1.jpg, service2.jpg, contact-banner.jpg

## Publish
1. Create a repo (e.g. `3d-endless-runner`) and upload all these files.
2. Settings -> Pages -> Source: "Deploy from a branch" -> main / (root) -> Save.
3. Site goes live at https://<username>.github.io/<repo>/
